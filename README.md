# Scalping Open Flow — Marathon

Questa cartella è pronta per GitHub Pages.

1. Carica **tutta** la cartella in un repository GitHub.
2. In GitHub apri **Settings → Pages**.
3. Seleziona il branch principale e la cartella `/(root)`.
4. GitHub pubblicherà `index.html` come presentazione navigabile.

La presentazione si controlla con frecce destra/sinistra, barra spaziatrice, click laterali oppure swipe da telefono.
